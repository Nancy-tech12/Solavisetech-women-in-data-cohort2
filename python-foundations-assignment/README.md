## 💡 Key Concepts Demonstrated

- **4 core data types**: `str`, `int`, `float`, `bool`
- **4 data structures**: `list`, `tuple`, `set`, `dict`
- **Operators**: arithmetic, comparison, modulus, power
- **Control flow**: `if/elif/else`, `for`, `while`
- **Built-in functions**: `input()`, `print()`, `type()`, `len()`, `max()`, `min()`
- **String formatting**: f-strings throughout
- **Real-world context**: Data analysis scenarios used in every exercise
