# Solavise Tech Women in Data - Cohort 2

## About the Program
Solavise Tech Women in Data is a 2-month intensive training program designed 
to equip women with practical, job-ready data skills including Python, GitHub, 
data analysis, and visualization — through live sessions, hands-on projects, 
and a final hackathon experience.

## About Me
Hi! My name is Nancy Yeboah. I come from a biological sciences background 
and I am currently transitioning into the world of data. I believe that data 
skills are the bridge between my scientific foundation and the tech-driven 
opportunities of today's job market.

## My Expectations
- To be part of a supportive community of women growing together in tech
- To get hands-on experience that goes beyond theory
- To build a portfolio that reflects real, practical skills

## What I Hope to Learn
- Python for data analysis and automation
- How to clean, explore, and visualize real-world datasets
- GitHub for version control and professional collaboration
- Beginner machine learning concepts
- How to present data insights confidently
